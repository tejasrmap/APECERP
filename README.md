# 📖 Overview

APEC ERP is a comprehensive Enterprise Resource Planning platform designed specifically for engineering and infrastructure organizations.

The platform centralizes organizational operations including employee management, attendance tracking, project execution, workforce monitoring, scheduling, reporting, and autonomous GPS-based location tracking.

The application was developed to eliminate manual workflows while providing real-time visibility into organizational operations.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/apec-erp.git
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Production build

```bash
npm run build
```
